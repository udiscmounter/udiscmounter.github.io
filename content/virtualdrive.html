How to add a virtual drive in uDiscMounter

To add virtual drives, it is recommended to run the program as administrator by right-clicking > Run as administrator. Then select the Add Virtual Drive menu and specify how many drives you want to add. After clicking Apply, you must restart the system to apply the changes.

If the program is not run as administrator, the Add Virtual Drive window will appear as shown in the image above, with the warning displayed in the image.
