uDiscMounter
Virtual Drive & Disk Image Mounting Software.

uDiscMounter Command-Line Arguments

Basic usage:

uDiscMounter.exe [argument]

Open a file directly:
uDiscMounter.exe "D:\images\game.iso"
Adds the file to the list and shows the Mount dialog so you can pick a drive.
This is what Windows uses when you double-click an associated disc image.

--mount <drive> <file>
Mounts the image to a specific drive.
Example:
uDiscMounter.exe --mount E: "D:\images\game.iso"
If the drive is in use, it warns you and falls back to the manual mount dialog.
If the drive is free, it mounts and opens the drive in Windows Explorer.

--auto <file>
Mounts the image to the first free virtual drive.
Example:
uDiscMounter.exe --auto "D:\images\game.iso"
If no free drive is found, it shows the manual mount dialog.

--eject <drive>
Ejects the image from the given drive.
Example:
uDiscMounter.exe --eject E:
If the drive is not mounted, it shows a message.
If mounted, it ejects, removes the file from the list, and refreshes.

Other -- arguments:
Any argument starting with -- that is not --mount, --auto, or --eject is ignored.
These are reserved for future use.

Examples:

Shortcut target:
"C:\Program Files\uDiscMounter\uDiscMounter.exe" --auto "D:\game.iso"

Batch file:
@echo off
"C:\Program Files\uDiscMounter\uDiscMounter.exe" --mount F: "D:\movie.iso"
pause

PowerShell:
& "C:\Program Files\uDiscMounter\uDiscMounter.exe" --eject E:

From another program (C#):
Process.Start(@"C:\Program Files\uDiscMounter\uDiscMounter.exe",
@"--mount E: ""D:\images\game.iso""");

Task Scheduler:
Use --auto "D:\images\boot.iso" to mount an image at startup.
